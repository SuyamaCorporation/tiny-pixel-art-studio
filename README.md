# タイニーピクセルアートスタジオ

16×16または32×32グリッドのピクセルアートエディター。ペン・消しゴム・バケツ塗り・スポイト・ライン描画ツールと32色パレットを搭載。アニメーションフレーム管理とPNGエクスポート機能付き。

## 機能
- 16×16 / 32×32グリッド切替
- 5種の描画ツール（ペン・消しゴム・バケツ塗り・スポイト・ライン）
- 32色プリセットパレット＋カスタムカラーピッカー
- Undo/Redo（最大20ステップ、localStorage保存）
- アニメーションフレーム管理（追加・削除・サムネイル表示）
- FPS調整付きアニメーションプレビュー
- ズーム1x/2x/4x切替
- グリッド表示トグル
- 5スロットのプロジェクト保存・読込（localStorage）
- フレーム単位のPNGエクスポート
- キーボードショートカット（P=ペン、E=消しゴム、F=塗り、I=スポイト、L=ライン、Ctrl+Z/Y）
